# ScreenRest

简体中文 | [English](README.en.md)

**一键假息屏小工具** —— 按下热键，屏幕瞬间变黑、鼠标隐藏，看上去就像显示器已经关了；但系统其实完全醒着：下载照跑、编译照转、挂机任务一个不停，绝不会自动息屏、睡眠或锁屏。再按一次热键，瞬间回到桌面。

## 🎬 什么场景用它

- 🌙 **下班偷偷挂机**：让 AI 帮你通宵跑任务，人可以先走——屏幕黑着像早就关机了，任务却在黑暗里跑得热火朝天，第二天回来直接收成果
- 🚶 **人走屏不亮**：离开工位去倒水、开会、摸鱼串门，不想让路过的人瞄到屏幕？一键黑屏挡住一切，电脑照常干活，回来热键一按接着用

## ✨ 它的直观优点

- ⚡ **快**：热键一按立刻黑屏，恢复同样瞬间完成，没有动画、没有等待
- 🪶 **小**：整个程序就是一个 10 KB 的 exe，绿色免安装，拷到哪用到哪
- 🎈 **简单**：双击启动、一个热键走天下，没有界面、没有设置、没有学习成本
- 💤 **轻**：常驻内存约 25~30 MB，对 GUI 程序来说相当苗条，后台默默无闻
- 🖥️ **多显示器**：几块屏就黑几块，整整齐齐
- 🤫 **低调**：托盘只有一个深灰小方块，不显示任何文字

## 功能特性

- 所有显示器变纯黑、隐藏鼠标光标，看起来像显示器已关闭
- 系统保持唤醒：黑屏期间不会自动息屏、睡眠或锁屏
- 热键秒切：`Ctrl+Alt+M` 黑屏 / 恢复，立即生效
- 防误触：黑屏时屏蔽键盘输入和 Alt+F4，遮罩窗不出现在 Alt+Tab 和任务栏
- 多显示器支持：每块屏幕一个黑窗
- 黑屏时自动关闭 RGB 灯光：检测到 [OpenRGB](https://openrgb.org) 即一键灭灯，未安装则自动跳过（托盘菜单可关闭此功能）
- 低调托盘：深灰色无文字图标，右键菜单可切换/退出

## 快速开始

1. 下载 `ScreenRest.exe`（约 10 KB，无需安装）
2. 双击运行，托盘出现深灰色小方块图标
3. 按 `Ctrl+Alt+M` 进入假息屏，再按一次恢复
4. 退出：右键托盘图标 → Exit

## 自定义热键

默认热键 `Ctrl+Alt+M`。编辑 `ScreenRest.cs` 顶部的 `HotKeyModifiers` / `HotKeyVk` 常量（虚拟键码，如 `0x4D` = M），重新编译即可。

## 从源码构建

双击 `build.cmd`。使用 Windows 自带的 .NET Framework C# 编译器（`csc.exe`），无需安装任何开发工具。产物为 `ScreenRest.exe`，拷贝这一个文件即可在其他电脑使用。

## 工作原理

- 为每块显示器创建无边框纯黑置顶窗口（`WS_EX_TOOLWINDOW`，不进 Alt+Tab），并隐藏光标
- 调用 `SetThreadExecutionState(ES_CONTINUOUS | ES_DISPLAY_REQUIRED | ES_SYSTEM_REQUIRED)` 持续压制系统空闲计时器，使 Windows 不自动关闭显示器、不睡眠、不锁屏
- 通过 `RegisterHotKey` 注册系统级全局热键，黑屏状态下同样响应

## 常见问题

**杀毒软件报毒？**
未签名 exe 偶有误报，可加入白名单或改名后重新编译。

**黑屏状态下按 Win 键会怎样？**
黑屏只是画面遮挡，系统按键（如 Win）仍会弹出系统界面。请根据场景自行判断，离开工位前锁好敏感内容。

**忘了热键 / 程序异常？**
按 `Ctrl+Alt+Del` 打开任务管理器，结束 ScreenRest 进程即可恢复。

**RGB 灯关了怎么开回来？**
OpenRGB 的命令行是无状态的，无法自动复原你原来的灯效（原模式参数读不全，也可能与厂商灯控软件互相覆盖）。建议：在 OpenRGB 图形界面里把常用灯效保存为 profile，想亮灯时加载它；或直接用主板/厂商软件重开。若灭灯无效，先以管理员身份运行一次 OpenRGB 让它识别设备。
